🗄️ Initialisation de la Base de Données

Cette page permet d'initialiser la base de données Firebase avec des données de test pour l'application des enseignants.

Que fait cette initialisation ?

  • ✅ Ajoute des étudiants de test
  • ✅ Crée des bulletins d'exemple
  • ✅ Ajoute des annonces du secrétariat
  • ✅ Crée des comptes enseignants

Note: Cette opération ne supprime pas les données existantes, elle ajoute seulement des données de test.

Après l'initialisation, vous pourrez utiliser teacher_clean.html avec des données réelles.
